# Chicago Housing Instability and Resource Allocation

## Project Overview

This project investigates housing instability and affordable housing distribution across Chicago. Its purpose is to identify measurable patterns and develop transparent, evidence-based resource allocation scenarios.

## Research Question

Which Chicago community areas show the greatest housing instability, how well does city-supported affordable housing align with that need, and how would priorities change under different allocation strategies?

## Project Status

This project is currently in development.

## Ethical Commitments

This project will distinguish between homelessness, housing instability, and doubled-up housing. It will document undercounting, sampling limitations, uncertainty, and possible bias. Correlations will not be presented as proof of causation.
