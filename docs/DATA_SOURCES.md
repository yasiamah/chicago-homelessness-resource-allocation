# Data Sources

This document records the sources planned for the Chicago Housing Instability and Resource Allocation project.

## Primary Sources

### Chicago Point-in-Time Count

Provides annual sheltered and estimated unsheltered homelessness counts. It is a one-night estimate and does not include all unstable housing situations.

### HUD PIT and Housing Inventory Count

Provides standardized historical homelessness and system inventory information for Chicago Continuum of Care IL-510.

### American Community Survey

Provides tract-level estimates for rent burden, income, poverty, tenure, vacancy, and demographics. ACS estimates include margins of error.

### HUD CHAS

Provides detailed housing-needs and cost-burden estimates for low-income households.

### Affordable Rental Housing Developments

Provides locations and unit counts for documented city-supported affordable developments. It does not provide real-time unit availability.

### Chicago Community Area Boundaries

Provides the geographic polygons needed for spatial joins and community-area maps.

## Supplementary Source

### Chicago Coalition to End Homelessness Estimate

Provides a broader annual estimate that includes doubled-up homelessness. It will be shown separately from PIT because the definitions and time periods differ.

## Measurement Rules

- Housing instability will not be labeled as observed homelessness.
- PIT counts will not be treated as complete annual counts.
- Different homelessness definitions will not be combined without explanation.
- Correlation will not be presented as proof of causation.
- Dataset dates and limitations will appear in the final report.
